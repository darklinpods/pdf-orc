# 架构决策记录

本目录使用轻量 ADR（Architecture Decision Record）保存重要取舍。

文件名格式：`NNNN-short-title.md`。

每条 ADR 包含：

- 状态：提议、已接受、已取代或已废弃。
- 背景：为什么需要做决定。
- 决策：采用什么方案。
- 影响：收益、代价和后续约束。
