# ADR 0001：采用本地网页应用形态（无后端、下载交付）

- 状态：已接受（待用户评审）
- 日期：2026-08-19

## 背景

用户对产品形态不敏感：网页或 native 均可，仅在本机使用也完全可以；且明示不在乎 PDF 的持久化——加载处理完，下载交付即可。候选形态有 native（Tauri/Electron）、本地网页应用、服务端网页应用。选型应优先考虑迭代速度与本场景的真实需求。

## 决策

采用纯前端本地网页应用：Vite 构建、浏览器打开、无后端；PDF 通过浏览器文件选择器载入内存，处理结果以下载方式交付。不引入登录、云存储、多设备同步。

## 影响

- 优点：迭代最快（无跨端编译、无部署）；跨平台一致（Mac/Windows 同一产物）；数据不出本机。
- 代价：大文件受浏览器内存限制，无法后台/离线长时间处理；无服务端意味着分享与备份依赖导出文件。
- 约束：不引入账号与服务端能力，除非用户后续明确改变诉求；若未来需要 OCR 等重计算，优先采用本地 Web Worker / WASM，仍无需服务端。
- 验证：构建产物在浏览器本地运行，全程无网络请求。
