# ADR 0006：拖动排序选型 @dnd-kit

- 状态：已接受（待用户评审）
- 日期：2026-08-19

## 背景

管理模式需要单页拖动排序 + 多选组拖动，且 hover 操作按钮（旋转/插入/删除）必须与拖动共存。候选：原生 HTML5 DnD（多选拖动、触屏、无障碍能力弱）、react-beautiful-dnd（已停止维护）、@dnd-kit（活跃维护，sortable 成熟，支持自定义碰撞与策略，无障碍支持好）。

## 决策

使用 `@dnd-kit/core` + `@dnd-kit/sortable` 实现排序与多选拖动；单页拖动与选中组拖动共用一套排序逻辑（未选中时拖单页，选中时拖整组）。

## 影响

- 优点：成熟、可定制、无障碍支持；生态活跃。
- 代价：多选组拖动需自定义 collision/strategy，属于已知复杂度，需在管理模式中单独验证。
- 约束：hover 操作按钮与拖动的事件冲突必须专门处理（见 conventions.md 交互约定）；不得因按钮插入而破坏拖动起点判定。
- 验证：200 页网格拖动排序流畅；多选组拖动、移动到首/尾、跨源移动均正确。
