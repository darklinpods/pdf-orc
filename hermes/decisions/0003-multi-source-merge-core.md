# ADR 0003：多源 PDF 合并作为页面管理的前提

- 状态：已接受（待用户评审）
- 日期：2026-08-19

## 背景

用户原始表述是"上传一个 PDF"，但事故案卷材料天然是多份扫描件（认定书、现场图、证件、保单、凭证等分属不同文件）。若只支持单源，拖动排序只能调整同一份文件内的页序，案卷整理的诉求只实现了一半。合并是排序的上游能力。

## 决策

页面管理基于统一 PageList，源可以是多份 PDF（导入时追加合并）；单源是特例而非独立路径。每页记录来源（sourceId + sourcePageIndex）。

## 影响

- 优点：合并、排序、导出在同一条链路完成，符合真实工作流。
- 代价：需要处理跨源页引用与重复导入（同一页重复导入视为两个独立页，由用户负责）；源文件释放策略更复杂。
- 约束：若评审确认不需要多源，可降级为单源实现，但保留 SourceRef 接口以维持扩展性。
- 验证：3–5 份扫描件导入后页序、来源标记正确；跨源拖动排序后导出正确。
