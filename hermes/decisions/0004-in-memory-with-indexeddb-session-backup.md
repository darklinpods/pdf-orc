# ADR 0004：内存态优先 + 可选 IndexedDB 会话备份

- 状态：已接受（待用户评审）
- 日期：2026-08-19

## 背景

用户明示不在乎 PDF 的持久化——处理完下载即可。服务端存储或本地数据库均属过度设计。但纯内存体验脆弱：浏览器刷新或误关会丢失全部整理进度。

## 决策

- 文档状态驻留内存，导出以下载交付（见 ADR 0001）。
- 提供可选的 IndexedDB 会话备份：保存源字节 + 命令日志，刷新后一键恢复；不做文件级持久化、不做自动保存承诺。
- MVP 可不实现备份，但文档核心命令的可序列化设计（见 ADR 0005）为其保留接口。

## 影响

- 优点：满足"不持久化"诉求的同时，防误刷新丢工作；实现成本低。
- 代价：备份需处理大文件字节存储，超限时应明确提示而非静默失败。
- 约束：备份是增强能力，不承诺跨设备、不承诺长期保留；恢复时必须校验命令日志可完整重放。
- 验证：刷新后会话恢复，页序、旋转、撤销栈一致。
